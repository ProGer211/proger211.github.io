## DESCRIPCIÓN

**proger211.github.io** es mi portfolio personal, creado para mostrar mi perfil como estudiante de Ingeniería Informática, mis conocimientos técnicos y algunos de los proyectos que he realizado durante mi formación universitaria.

El sitio presenta información sobre mi perfil, tecnologías, proyectos destacados, formación académica y formas de contacto. Actualmente busco **prácticas curriculares**, lo único que me queda para terminar la carrera.

## FASES DEL PROYECTO

### 1. Planificación

- Definición de los objetivos del portfolio
- Selección de la información relevante del perfil
- Organización de los proyectos y tecnologías
- Diseño de la estructura y navegación del sitio

### 2. Diseño

- Diseño de una interfaz moderna y profesional
- Organización de las diferentes secciones
- Diseño adaptable a diferentes tamaños de pantalla
- Definición de la estructura visual y distribución del contenido

### 3. Implementación

- Desarrollo de la interfaz con React y TypeScript
- Estilos personalizados con CSS3
- Compilación y desarrollo local con Vite
- Integración de proyectos y enlaces externos

### 4. Pruebas

- Comprobación de la navegación entre secciones
- Verificación de enlaces
- Pruebas de visualización en diferentes tamaños de pantalla
- Corrección de errores de interfaz y funcionamiento

### 5. Despliegue

- Publicación automática mediante GitHub Actions y GitHub Pages
- Cada cambio subido a `main` compila y publica la web
- Actualización del portfolio mediante Git

### 6. Mantenimiento

- Actualización de proyectos
- Incorporación de nuevas tecnologías y conocimientos
- Actualización de información académica y profesional
