## Portfolio personal desarrollado para presentar mi perfil, proyectos y experiencia en desarrollo de software.

## DESCRIPCIÓN

**proger211.github.io** es mi portfolio personal desarrollado para mostrar mi perfil como estudiante de Ingeniería Informática, mis conocimientos técnicos y algunos de los proyectos que he realizado durante mi formación universitaria.

El sitio presenta información sobre mi perfil, tecnologías, proyectos destacados y formas de contacto, funcionando como una presentación profesional de mi trayectoria y experiencia.

---

## FASES DEL PROYECTO

### 1. Planificación

- Definición de los objetivos del portfolio
- Selección de la información relevante del perfil
- Organización de los proyectos y tecnologías
- Diseño de la estructura y navegación del sitio

### 2. Diseño

- Diseño de una interfaz sencilla y profesional
- Organización de las diferentes secciones
- Diseño adaptable a diferentes tamaños de pantalla
- Definición de la estructura visual y distribución del contenido

### 3. Implementación

- Desarrollo de la estructura mediante HTML5
- Aplicación de estilos mediante CSS3
- Implementación de elementos interactivos con JavaScript
- Integración de proyectos y enlaces externos

### 4. Pruebas

- Comprobación de la navegación entre secciones
- Verificación de enlaces
- Pruebas de visualización en diferentes tamaños de pantalla
- Corrección de errores de interfaz y funcionamiento

### 5. Despliegue

- Publicación mediante GitHub Pages
- Configuración del repositorio como sitio web
- Actualización del portfolio mediante Git

### 6. Mantenimiento

- Actualización de proyectos
- Incorporación de nuevas tecnologías y conocimientos
- Actualización de información académica y profesional

## PROYECTOS DESTACADOS

Entre los proyectos presentados en el portfolio se encuentran:

- **codeEvaluator:** Plataforma web de evaluación automática de código desarrollada como Trabajo de Fin de Grado.
- **Football API:** Aplicación relacionada con información de fútbol mediante una API REST y arquitectura MVC.
- **Minería de Datos:** Proyecto relacionado con el tratamiento y gestión de datos.
- **Robocode:** Proyecto académico desarrollado en Java mediante Robocode, programando tanques autónomos para combatir y cumplir objetivos específicos.
